# 📊 Data Professional Survey Breakdown

This Power BI project presents a detailed analysis of a global survey conducted among data professionals. The dashboard delivers insights into average salaries, job roles, industry comparisons, satisfaction levels, and programming language preferences across various countries.

---

## 📁 Project Overview

The goal of this project is to:
- Explore salary trends by industry, job title, gender, and geography.
- Understand job satisfaction and work-life balance among data professionals.
- Visualize preferences for programming languages.
- Build an interactive dashboard for stakeholders to explore key insights.

---

## 🧾 Dataset

- **Source:** [Kaggle - Data Professional Survey Breakdown](https://www.kaggle.com/datasets/ahmedmohamedibrahim1/data-professional-survey-breakdown)
- **Size:** 261 responses
- **Fields Include:**  
  `Country`, `Age`, `Gender`, `Job Title`, `Industry`, `Salary`,  
  `Programming Language Preference`, `Work-Life Balance`, `Happiness with Salary`, etc.

---

## 🔍 Key Insights

- 💼 **Finance** and **Tech** sectors reported the highest average salaries.
- 🧑‍🔬 **Data Scientists** lead in salary among all roles.
- 🌐 **United States** has the highest number of participants.
- 🐍 **Python** dominates as the most preferred programming language.
- ⚖️ Average **Work-Life Balance** rating is **6.38/10**.
- 💸 **Happiness with Salary** averages **5.0/10**, indicating possible discontent.
